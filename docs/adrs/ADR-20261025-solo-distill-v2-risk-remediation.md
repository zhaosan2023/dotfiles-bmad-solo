## 背景与选择依据

[提案的历史覆盖记录](../../PROPOSAL-20261023-fastcode-knowledge-distillation.md:82)仅作为待核验基准，不继承历史测试通过或源码身份。候选域、来源表示和配额政策存在结构性变化，因此以显式 V2 契约实施增量，不静默替换 V1 或场景 B。

## E0：执行前提（保留历史门禁）

以下为实施前的原始前提契约；E0—E4 的历史交付以绑定计划为准，不将早期未接管措辞作为当前环境状态。

- 先取得目标工作区的真实原生访问证据，读取实际项目规则、代码、测试、依赖声明及既有改动；保护用户未提交内容。
- 核验实际 Python 3.12 环境及纯标准库路径，不安装第三方依赖，不导入或运行参考项目。
- 核验测试、冻结评价和历史回执的真实资产范围。缺口只阻塞依赖事项，不要求 E0 执行未获准的模型或宿主验收。
- 精确实现与独立认证入口已在绑定计划 E0—E5 实例化；本 ADR 不用静态文档制造运行时能力或资产证明。

## E1：公共引用与合法语法单元

- V2 独立版本解码，定义与语句使用不同判别类型；保留 V1 语义及场景 B 定向定位边界。
- 支持完整定义、装饰器、模块顶层语句与主保护块。主保护条件支持形式须在实现前明确，不能把任意条件块认证为主保护块。
- 分开 AST UTF-8 列坐标、原始编码字节坐标与完整正文范围，覆盖同行语句、非 ASCII、非 UTF-8、BOM 和装饰器。不能只使用起止行判定身份。
- 公共注册表为文件、单元、正文所有者、来源、条件、角色证明、事实、关系和义务提供唯一身份及紧凑引用；引用目标类型、范围和闭包必须可检查。
- 父子别名仅在真实完整正文包含子单元时成立；类头、错位范围或整个模块不得伪装为一块完整定义。
- 角色证明保持单一权威集合；来源存在不提升证据等级。总体状态由来源、义务满足规则及故障推导，不接受模型自报完整。

## E2：预留、单向借槽与原子成本

- 角色按语法证据分类为入口、装配、状态编排、持久化及边界／辅助；多标签、角色证明、正文所有权和管道归属相互独立。
- 先归并全部必需来源、条件及关系闭包，冻结必需预留，再填充可选节点。完整正文唯一计费；多个角色满足仍逐项核验证据。
- 基准为 16 骨架、12 上下文、4 异常块，总计最多 32 块、98,304 UTF-8 正文字节。可选上下文每文件最多两块；必需上下文仍受总预算约束。
- 仅必需骨架溢出可借未预留上下文槽。借槽量为必需骨架超出 16 的块数，不得超过上下文基准扣除必需上下文后的余额；异常额度不借出。
- 辅助节点不能通过必需标记、多标签或中心度取得骨架资格；可选骨架不能触发借槽，上下文不能反向侵占骨架槽。
- 父子所有权替换或新增必需闭包时重新试装整个组合，原子提交；失败不留下半组选入或部分扣减。
- 固定骨架后仅一次确定邻接展开，新上下文不成为种子。独立已消歧邻居去重后使用 d/(d+8) 饱和，仅在同角色、同结构信号档位内破同分，使用整数／有理数比较。
- 未知目标保留调用点及原因，但不进入确定图；关系层、条件、展示方向、循环及重绑定须明确处理，不声称静态图证明运行时执行顺序。
- 必需替代组若需要有界搜索，须在执行前实例化版本化稳定顺序及展开状态上限；搜索耗尽、政策拒绝和已证明不可容纳分别报告。

## E3—E5：完整帧、封存核心与无损紧凑传输

- 唯一编码入口同时用于完整帧计量与发送；A 上限 min(22,016, 调用者预算)，B 上限 min(12,288, 调用者预算)，真实身份、嵌套转义和换行均计入。必需来源及支持闭包不可裁减，最小必要帧超限诚实阻塞。
- 已认证核心按输入与政策身份封存；动态主机根、观测和任务增量不改变核心前缀。任务与核心使用独立引用空间，不宣称远端缓存命中。
- zlib-base64-core-v2-1 仅显式 V2 A 启用；标准库压缩规范 JSON，携带精确解码长度，上限 1,048,576 字节。严格检查类型、版本、规范 Base64、解压上限、精确长度、流结束及尾随数据，随后复用完整身份、清单、来源与状态认证；独立消费者不导入生产编解码器。
- 压缩不裁减核心语义、完整文件分母、必需闭包或最坏元数据预留；默认 JSON、V1 和 B 不静默变化。不可压缩必需内容仍阻塞，不承诺任意样本均可容纳。
- 用户将本轮 E5 验收收窄为离线风险修复出口；既有 20,188 字节帧是用户确认依据，本轮未重测。真实 A 的 13/13 独立语义／时间、完整 B、三轮、宿主、端到端取消／清理、第二项目和缓存收益保留为本轮外门禁，缺口不记通过。

## 阶段验收与命令边界

用户明确批准的离线测试命令为：

```bash
PYTHONPATH=src timeout --kill-after=2s 30s python3 -B -m unittest discover -s tests -p 'test_*.py' -v < /dev/null
```

仅在真实目标工作区、资产与执行前提核验后运行。命令串行、前台同步、封闭标准输入；探测采用 15 秒进程级上限。非零收集、无跳过和退出码 0 必须从实际回执确认，超时或必要证据缺失不通过。

- E1：独立正负控覆盖重复键／身份、悬空索引、错类型、布尔冒充整数、过期身份、同行错位、装饰器、非 UTF-8、主保护伪造、父子伪别名及受影响调用方。
- E2：覆盖 18 必需骨架＋5 必需上下文可容纳、17 必需骨架＋12 必需上下文按政策拒绝、辅助反向借槽、可选借槽、所有权替换、多标签重复扣减、新增必需闭包、重复邻居、条件／循环／重绑定及动态目标负控。
- 独立测试不以生产分类器作为唯一神谕，不改冻结答案、不降低断言。E1 必需门禁通过后才推进 E2。
- 保持场景 B 的离线受影响边界兼容，不把离线测试称为模型、真实宿主或完整场景 B 实测通过。

## 后果与未授权出口

V2 引用闭包及调度变化需要新增认证与负控测试，但避免重型依赖和全局求解平台。合法来源、多标签或槽位可容纳均不证明 13/13 语义覆盖。

完整帧、发送字节一致性、封存前缀、消费者与紧凑编解码由离线回归覆盖；最终指定命令非零收集 205 项，5.186s、退出码 0、OK，无单测跳过，真实输出由平台命令工件 cmd-1793000678635.txt 定位。该结果满足修订后的本轮必需出口，不证明真实 13/13、完整 A/B、宿主或缓存收益。

当前进度仅以平台任务记录引用真实回执，控制器覆盖未证明；本 ADR 保存决策及有界接受依据，不镜像逐轮流水。用户已授权本任务离线范围接受与计划归档；事实基线写入仍未授权。以后若要求运行时声明，须另行授权并取得对应证据，不能继承本轮离线绿灯。
