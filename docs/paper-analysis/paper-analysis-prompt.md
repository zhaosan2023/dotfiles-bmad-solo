## 🐦 第一遍扫描：全局俯瞰 (The First Pass)
**目标**：用 5-10 分钟快速把握核心脉络。
请阅读标题、摘要、引言、各节小标题和结论，然后精炼地回答“5C”问题：
1. **类别 (Category)**：这是什么类型的文献？（如：测量类论文、系统分析、研究原型描述等？）
2. **背景 (Context)**：它与哪些其他论文/领域相关？分析该问题使用了哪些理论基础？
3. **正确性 (Correctness)**：其核心假设看起来是否有效？
4. **贡献 (Contributions)**：这篇论文的主要贡献是什么？
5. **清晰度 (Clarity)**：文章写得好吗？结构是否清晰？
*给出第一遍的结论：这篇文章是否值得继续深入阅读？*

## 🔍 第二遍解析：把握核心 (The Second Pass)
**目标**：掌握论文内容，忽略繁琐细节（如具体推导证明）。
1. **核心主旨总结**：用通俗易懂的语言总结本文的核心论点和支撑证据。
2. **关键图表解析**：仔细查看文中的图表（Figures, diagrams, and other illustrations）。指出哪些图表最关键，它们说明了什么趋势？（例如坐标轴是否合理？是否有误差线以证明统计显著性？）
3. **关键参考延伸**：列出文中反复引用的、未读过的核心前置文献，作为了解背景的突破口。

## 🧠 第三遍深度聚焦：批判与重构 (The Third Pass)
**目标**：深度理解，甚至能在脑海中“虚拟重现 (virtually re-implement)”这项研究。
为了帮助我（用户）进行第三遍深度阅读，请你指出我应该聚焦的“突破口”：
1. **隐藏的假设与潜在缺陷**：作者在方法或逻辑中做了哪些隐式假设？实验或分析技术有什么潜在问题？
2. **复现思路**：如果我要重新实现这篇论文的工作，我需要重点关注哪几个技术细节或公式？
3. **未来工作方向 (Future Work)**：基于当前的局限性，有哪些可以继续深挖的研究方向？
