# BMAD-Solo 敏捷工程循环与自适应安全阀 (Core Methodology)

本文件定义 BMAD-Solo 的核心工程循环与实证背压机制。

## 1. 意图、授权与三级生命周期路由
启动任务先判断只读、结晶、实施、继续或重放意图；读取计划不等于获得执行授权。
1. 用户显式指定计划时，只读取该候选契约，跳过默认暂存入口。指定文件缺失或非法时报告可恢复阻塞，可发现候选但不得静默替换。
2. 没有显式路径时，才探测 `_bmad-output/pending_implementation_plan.md`；相关且有效才绑定，无关计划不抢占任务，多任务冲突时请求选择。
3. 默认暂存入口缺失是正常状态，不重复盲读。继续历史任务时检索 `_bmad-output/archive/plans/`，展示匹配依据；不得自动执行最新归档。无候选时按意图空闲、请求选择或提出新方案；明确的小修复与运维任务可走轻量路径。
4. 文件缺失、权限拒绝、磁盘错误和格式损坏分别报告；历史计划默认只读，恢复或重放须显式授权、建立保留来源的新执行实例并重新验证，不继承历史绿灯。
5. 绑定计划路径、标识、契约版本与阶段；校验集中在接管、契约变化和阶段边界，外部变化先停止对账，不要求逐修改绑定或模型手工同步指纹。读取 `_bmad-output/project-context.md` 作为事实基线；仅权限与任务允许时检查 Git 状态，保护既有改动，不绕过分析模式的终端限制。
6. 只读任务仅取证和会话交付，不写文件、不运行验证、不转正或归档；任务复杂度不能扩大授权。
7. 工程直接消费明确需求或获准方案，不重复完整分析。必要实验先核对问题、范围、环境前提与验收，再由获准工程入口执行；不自动启动实验，不把模式切换或草稿路径当作执行许可或沙箱。

状态契约：`INTAKE → READ_ONLY / IDLE / NEEDS_SELECTION / READY`；获准实施后 `READY → EXECUTING → VERIFYING → COMPLETED → ARCHIVED`。执行或验证失败进入 `BLOCKED`，明确暂停进入 `SUSPENDED`，获准恢复后重新校验再进入 `READY`。

## 2. 按场景选择验证
- `algo`：算法适配、性能约束、架构预检与阶段相关验证。
- `structural`：针对受影响接口、数据所有权与跨层依赖预检，执行契约指定的配置、隔离分发或相关单测，不附加算法检查或无关业务测试。
- `bugfix`：改动影响范围内最小充分回归与自审，不强制重型规划，不建立或转正 ADR。
- `ops`：差异审查与配置语法校验，不运行业务单测。
- 相关验证覆盖必要的接口、调用方、所有权与副作用边界，不仅限被编辑函数，也不盲跑全库；属性测试与缺陷回归及必要集成边界互补，不按比例删测。

## 3. 阶段门禁与状态单源
- 按获准的 Phase / Epic 实施并执行指定验证；资产未创建时先实现。命令遵循宪章的串行、进程级超时、前台同步、输入封闭与工具正交要求。
- 证据包含真实命令、工作目录、退出状态、关键输出及目标。普通失败可在当前权限与预算内修复，但失败不登记完成、不推进依赖；超时、取消、缺依赖、零命中、必需项跳过、缺证据或清理未知即阻塞，不降低断言，通过后才推进。空输出按具体操作的必需证据判断，不一律失败或认定成功。
- 环境准备与测试分离；测试不隐式联网安装依赖。必要实验只按获准的问题与范围返回真实回执，不扩大为其他任务或宿主激活。
- 当前任务进度仅使用一个权威入口：控制器真实可用且覆盖本任务时使用其核验的任务清单，状态卡仅为程序生成的只读视图；未实现或未覆盖时临时使用平台任务记录引用真实回执，披露覆盖缺口，不另建账本或宣称已有程序防篡改保证。
- 计划与 ADR 保存契约及决策，不保存逐轮流水，不要求模型手工同步元数据、指纹或历史通过记录。状态保存不触发业务重测或递归复验；实现、契约或环境变化须重验受影响的证据。
- 接管只提供目标、授权边界、状态视图和相关差异定位；80 行与配置字节预算是默认规划目标。先保留全部未完成事项、不变量及必要支持闭包，再去重和无损压缩；纯软超限仅结构化提醒并记录完整预算遥测，按双方声明能力协商大帧或分片。实际硬能力不足、未协商能力或必需信息缺失才阻塞，不静默丢失，不扩大外发范围、请求数或时限。完整日志留在授权工作区，模型只接收当前必需结果；静态配置和参考模型不证明 Roo 运行时权限或模型行为。

## 4. 完工对账与闭环 (Completion Gate)
- 仅获准实施的任务进入闭环；对照实现差异、相关验证输出与架构边界。阶段交付不等于全计划完成，明确暂停时保留未完成事项。
- 仅绑定契约要求关联 ADR、全部必需门禁通过且取得转正授权时，将对应提案更新为 ACCEPTED；缺少必需目标版本或运行时证据时保持 PROPOSED，不转正其他任务的 ADR。
- 仅取得相应写入授权时登记已经验证的架构事实及真实溯源，不编造会话标识；阶段交付不自动更新项目事实基线。
- 仅全计划完成且获准归档时处理实际绑定的活动计划，不固定清空默认暂存路径。目标包含时间及计划标识且不得覆盖；确认完整保存后再复核源标识与内容版本，源已变化或保存失败则保留源。
- 历史输入和其他暂停任务保持独立；没有绑定计划的轻量任务不执行计划归档。
