# Record Findings Procedure

## Trigger
- 重大 Bug 修复完成后需要复盘
- 容灾恢复过程结束
- 发现影响架构的关键经验教训
- Operator 模式下的重大排错结论

## Process

仅在当前用户授权及平台实际权限内持久化；只读咨询和审核仅会话交付，不写文件、不运行验证、不转正或归档。发现重要问题本身不增加写入或实施权限。

1. **分类 Finding**：
   - 涉及必要架构决策或重大技术选型：按获准 ADR 流程保存提案与依据，不自动转正。
   - 涉及项目全局事实：仅在另获相应写入授权且有真实验证溯源时更新事实基线；分析角色不更新该基线。
   - 仅涉及当前任务的发现：使用已选定的唯一任务进度入口；控制器未覆盖时临时引用平台任务记录与真实回执，不猜测文件路径或创建镜像账本。
   - 不确定？→ **停下来询问用户**

2. **获准产物**：按分类和核心规则使用实际绑定路径或对应默认路由；没有创建的文件不列为已交付，文档保存不表示验证通过。

3. **可选知识交接**：只有当前平台确实具备相应能力、发现适合跨任务复用且用户需要时才建议知识固化，不假定命令存在，不把局部结论外推为通用已验证事实。

## 禁止行为
- 不得将 Findings 放入 `docs/` 或项目根目录的任意 `.md` 文件中。
- 不得将具体事件的复盘报告覆盖或冒充 `project-context.md`。
- 不得在不确定归属时自行创建新目录或文件名。
