# BMRalph V5 能力导航

本索引只导航，不保存任务进度、项目事实或验证流水。按当前任务选择必要材料，不默认加载全部流程、完整日志或历史聊天。

## 本地流程

| 能力 | 触发条件 | 本套件入口 | 依赖与证据边界 |
|---|---|---|---|
| 工程实施 | 明确需求或获准计划需要实施 | [实施流程](procedures/build.md) | 实际读取、编辑及终端权限；文档存在不证明执行器或目标环境可用 |
| 代码审查 | 需要核对实现差异与验收 | [审查流程](procedures/code-review.md) | 当前源码、差异与真实回执；只读审查不执行验证 |
| 三遍阅读 | 用户要求评估方案、论文或重大架构取舍 | [分析流程](procedures/three-pass-analysis.md) | 获准读取、浏览及受限文档编辑；推演不替代实测，也不授予实施权限 |
| 类型化验证与状态查询 | 已获准的本机 Python 单测或明确采用类型化清单的计划 | [验证契约](procedures/verification.md) | 环境须先显式登记；查询不重跑业务、不保存进度，未覆盖操作不回退或虚构接口 |
| 受控启动输入组装 | 明确采用类型化清单，需要组装一个当前就绪任务 | [输入与预算契约](procedures/verification.md) | 明确请求与定向源码，只读核验来源快照；不启动 Agent，不证明授权、反馈或宿主自动加载已核验 |

这些是物理纳入 V5 的本地 Markdown 流程，不代表已注册为宿主技能或可独立调用的运行程序。可用工具及权限以当前平台的真实声明和回执为准。

## 双入口与规则

- [分析入口](../../ana-solo/SKILL.md)：三遍阅读、探索、审计及目标收敛；只读任务会话交付，获准结晶才修订同一计划与提案。
- [工程入口](../SKILL.md)：直接消费明确需求与现成方案，不为普通小修复重新生成完整分析或 ADR。
- [核心规则](../../../rules/bmad-core.md)：路由、授权、唯一进度、证据失效及阶段交付边界。
- [工程规则](../../../roo/rules-bmad-engineer/01-bmad-engineer-core.md)：相关验证、环境分层、失败阻断和成果保留。
- [分析规则](../../../roo/rules-ana-architect/01-ana-solo-core.md)：三遍阅读与只读权限边界。
- [计划模板](templates/implementation-plan.template.md)：仅在需要并获准建立计划时实例化，不覆盖未完成活动任务。

入口切换、读取计划、流程文档存在或可行结论均不扩大授权。阶段通过不等于全计划完成。

## 代码定位：按需搜索而非事实镜像

1. 从当前获准任务取得目标行为、受影响接口和验证目标，不先扫描整个仓库。
2. 使用当前平台实际可用的文件搜索找到定义、直接调用方和相关测试；索引失效时重新定向搜索，不猜测文件或接口。
3. 读取足够完整的源码块，核对路径、行号及调用关系；导航描述不作为源码事实或验证证据。
4. 接管输入只保留必要路径定位、未完成修改和最近有效反馈；完整源码、日志及历史按需读取。

本套件的方法文档不复制任务项目的模块清单。任务源码、调用方、测试和回执属于授权任务工作区，不能因套件位置改变而误定位到分发源。

- 进程监督：[监督模块](../../../scripts/bmad_supervisor.py)由[执行模块](../../../scripts/bmad_execution.py)调用；超时、取消、输出与路径边界见[监督器反例](../../../tests/test_supervisor_guards.py)。

- 当前计划与源码输入：[输入接入模块](../../../scripts/bmad_context_inputs.py)由[类型化入口](../../../scripts/bmad-exec.py)调用，复用[状态投影](../../../scripts/bmad_state.py)和[上下文预算](../../../scripts/bmad_context.py)；任务选择、来源快照及只读边界见[输入组装反例](../../../tests/test_context_inputs.py)和[入口测试](../../../tests/test_exec_cli.py)。

- 套件读取租约：[租约模块](../../../scripts/bmad_suite_lease.py)复用已有固定部署锁，由[来源绑定模块](../../../scripts/bmad_suite_source.py)调用；套件内直接调用反例见[租约测试](../../../tests/test_suite_lease.py)。公共部署入口对同一部署根的仓库更新、分支切换、标签缓存准备、新版移交及最终部署采用排他锁协议，与共享租约互斥；公共部署回归属于来源仓库的工程验证，不作为分发后运行依赖。租约自身不核验来源、不监督进程，尚无任务期循环调用方或 CLI 子命令；不保证跨部署根的共享来源冻结，边界见[租约说明](procedures/verification.md)。
- 已部署来源绑定：[来源绑定模块](../../../scripts/bmad_suite_source.py)组合共享租约与 V5 身份、受管物理资产、来源摘要及分发映射核验；直接调用反例见[来源绑定测试](../../../tests/test_suite_source.py)。仅读取明确部署根，不访问记录中的来源仓库；来源未知或边界变化时阻塞，不补造记录、不恢复旧文件。尚未接入活动任务或任务期循环，不替代宿主模式语义、事务完成诊断、运行时加载、同账号防篡改或取消后进程清理；完整边界见[来源绑定契约](procedures/verification.md)。

状态模块仅提供候选只读投影，没有完成写回操作；不能据此迁移当前活动计划或宣布完整任务控制器可用。契约、参数与覆盖缺口见[验证说明](procedures/verification.md)。

## 运行能力与遗留资产

- 类型化验证执行器、上下文组装及任务期循环以实际生产程序、已覆盖操作和当前验证回执判定可用性，不从本索引推断已实现或已通过。
- 控制器未实现或未覆盖当前操作时，披露缺口并使用获准受控命令；当前平台任务记录是唯一临时进度入口，不同时维护第二份进度。
- 独立 Roo 运行时、新会话、认证、规则加载、工具权限和断开后的两轮推进须分别核验；本地流程、静态契约及模拟测试不能代替目标运行时证据。
- 未识别或未注册的遗留技能仅为研究候选，不列为可用依赖，不虚构调用参数。需要其他能力时先核验最小必要资产，不以整库接入为前置条件。
- 本轮从 V4 只读参照并重写了实施、审查和三遍阅读流程，移除固定进度路径、无条件持久化和强制全过程前置；实际运行只引用本套件资产，不继承历史通过记录。
- 安装、更新、分发及 IDE 重载不启动 Ralph，不准备模型认证；远程启动、提交、推送和生产部署分别授权。
