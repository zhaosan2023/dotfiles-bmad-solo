# 实施计划模板

## 契约实例化

- 此模板不是可执行计划；填写唯一标识、实际授权、关联 ADR 与适配验证命令后才能接管。
- 场景：algo、structural、bugfix、ops；影响级别：S、M、L；验证类型：unit_test、config_syntax、diff_cleanliness。
- requires_adr 为 true 时引用真实关联 ADR，否则 adr_file 为 null。未知会话标识保持 null。
- AVAILABLE 仅表示验证资产存在，不表示依赖就绪或通过；未创建的资产保持 PLANNED_NOT_YET_CREATED。
- 命令按实际接口填写，串行、前台同步、输入封闭，探测 15 秒、验证 30 秒、构建 600 秒；不编造参数或运行时能力。
- 接管、契约变化及阶段边界核验绑定；不逐修改绑定，不要求模型手工计算或同步指纹。

## 目标

填写当前任务目标及明确的非目标，不以实施顺序调整放宽验收。

## 授权与边界

填写获准阶段、任务工作区及预算；真实宿主、远程任务、提交、推送和生产部署分别授权。
显式计划优先，默认缺失正常；新任务不默认搜索归档，不无条件覆盖未完成活动任务。
历史恢复须授权、新实例与重验。只读任务不实施、不验证、不转正或归档。

## 验收标准

- 填写必需的行为与失败条件；验收列表是稳定承诺，不作为第二份人工进度账本。
- 静态契约、隔离分发、本地模拟与真实运行时分别列出，不互相外推。

## 架构边界

填写受影响接口、数据所有权、依赖、历史不变量及相关 ADR；仅对重要边界变化做适用预检。

## 任务清单

- [ ] T1：填写可验证任务、依赖、源码落点与验证目标。

此清单是 V5 目标任务进度唯一载体，允许任务拆分、顺序调整与必要发现；关键决策、授权扩大或验收放宽须明确决定。
控制器已实现且覆盖当前任务时，从真实回执核验完成并生成只读状态视图，不另建人工账本；未实现或未覆盖时，当前平台记录作为唯一临时进度入口，不同时勾选本清单镜像进度，不宣称程序防篡改保证。

需要类型化候选投影时，按[验证契约](../procedures/verification.md)明确实例化唯一任务清单，并核对计划标识、验证选择、依赖和全部未完成事项；不得将本模板的普通复选框直接解释为类型化进度。
当前候选投影仅覆盖本机 Python 单测契约，没有完成写回操作，不自动迁移活动计划或平台进度。进度所有权切换须在接管或契约变化边界明确决定；未覆盖门禁仍保留，不继承历史通过结果。

## 验证矩阵

按阶段填写实际命令、目标、资产状态、必需证据与通过判定；缺资产先实现，失败、超时或缺证据进入 BLOCKED。
完整日志与回执保存于授权任务工作区，不写入套件分发源；回执记录命令、工作目录、退出结果及关键输出，不在计划或 ADR 镜像逐轮流水。
状态视图至多 80 行且受字节预算限制，启动输入和累计工具结果分别设预算；未完成事项无法完整表示时阻塞，不静默丢弃。
保存进度不触发业务重测，相关实现、测试、契约或环境变化后仅重验受影响证据。

## 停止、交付与归档

- 明确暂停进入 SUSPENDED；失败进入 BLOCKED，获准恢复并核验边界后进入 READY。
- 普通失败可预算内修复，不推进依赖；认证、权限、预算不足或无法确认在途进程结束时停止并保留成果。
- 阶段通过不等于全计划完成；全计划仅在全部必需门禁通过后完成。
- 缺必需运行时证据保持关联 ADR 为 PROPOSED；转正与登记已验证事实按契约及实际授权执行，不记录提案为事实。
- 只归档绑定、已完成且获准归档的活动计划；目标含时间及标识，禁止覆盖，完整保存后复核源版本，失败保留源。历史输入、其他暂停任务及轻量无计划任务不处理。

## 回滚

只恢复本任务经核对的受管改动，保留既有修改及并发变化；远程任务先取消并确认进程结束，不自动丢弃失败轮次成果。
