# 类型化验证与任务清单契约

本页说明已提供的接口及其边界，不保存任务进度或历史通过记录。实际能力以当前源码、授权及真实回执为准；文档和帮助输出不是验证通过证据。

## 操作选择

接口定义见[类型化入口](../../../../scripts/bmad-exec.py)，运行裁决见[单测执行模块](../../../../scripts/bmad_execution.py:140)。

- `register-env`：必须明确提供 `--workspace`、`--environment-file`、`--backend native-python` 和 `--python`；可重复指定 `--dependency` 或 `--executable`。仅登记已准备的环境，不安装依赖，拒绝覆盖已有登记。
- `check-env`：必须明确提供 `--workspace` 和 `--environment-file`。只读复核已有环境；缺依赖、身份变化或登记缺失时阻塞，不隐式登记或修复。
- `unit-test`：必须明确提供 `--workspace`、`--environment-file`、`--directory` 和 `--pattern`。可使用 `--minimum-tests`、重复的 `--required-test`、重复的 `--input` 及 `--runtime-directory`。默认测试下限为 1，运行目录为工作区内 `.bmad-runtime`。
- `check-evidence`：必须明确提供 `--workspace` 和 `--verdict-file`。从已有验收回执核验环境、目标、结果及覆盖文件身份，不重跑业务测试，不改写旧证据。
- `render-state`：必须明确提供 `--workspace` 和 `--plan-file`。仅投影明确采用下述任务契约的计划，不迁移平台进度、不勾选任务、不保存第二份状态。可降低 `--maximum-lines` 和 `--maximum-bytes`，不能超过 80 行及 16384 字节硬上限。
- `assemble-input`：必须明确提供 `--workspace`、`--plan-file` 和 `--request-file`；可指定 `--maximum-bytes`。从当前类型化计划选择请求指定的就绪任务，只读组装明确源码和必要输入，不启动 Agent、不执行测试、不保存进度。请求不能自行提供状态投影或验证契约。

当前验证后端仅为本机 Python 单测。配置语法、专项竞态、固定 GCC/musl 镜像、容器退出清理及远程 Agent 不属于这些接口已覆盖的能力；不得虚构对应子命令。

## 工作区与验证证据

- 任务源码、环境登记、完整日志和回执属于授权任务工作区；运行目录不得位于套件分发源或选中的测试目录。
- 环境登记与单测执行分离。环境复核会限时探测现有解释器与依赖，不执行安装；这不是网络隔离或恶意代码沙箱。
- 单测进程回执与验收回执分别保存。进程退出零、日志保存成功或摘要读取成功均不能单独证明测试通过。
- 零命中、必需测试缺失、跳过、预期失败、真实失败、超时、取消、清理失败或缺少完整结果均不能产生通过裁决。
- 测试目录和显式 `--input` 文件定义实现覆盖范围。未声明导入、依赖包全部源码、同账号防篡改及宿主权限隔离不在保证范围。
- 完整日志程序侧保留，默认输出有界摘要并标明截断。可从完整证据判定结果时，摘要截断本身不要求重跑。
- 相关实现、测试、运行器、受覆盖控制器或环境变化会使旧证据失效；无关文档编辑及状态保存不触发业务重测。
- 旧回执缺必要身份字段时阻塞，不通过补造字段或继承历史通过结果修复。

## 受控输入与累计输出预算

输入接入见[计划与源码组装模块](../../../../scripts/bmad_context_inputs.py)，字节计量与累计输出原语见[上下文预算模块](../../../../scripts/bmad_context.py)。这些模块不替代完整计划接管、授权核验或独立运行时适配。

- 输入请求为工作区内的 JSON 文件，必须且只能包含十个字段：`goal`、`authorization`、`task_id`、`constraints`、`capabilities`、`code_files`、`unfinished_files`、`feedback`、`observed_host_bytes`。重复字段、缺字段或额外字段均阻塞。
- 目标、授权及任务标识为明确非空文本；约束、能力和反馈为文本列表；源码与未完成修改为无重复的相对文件路径列表。没有相应材料时明确使用空列表，不自动扫描历史或整个工作树。
- 请求指定的任务必须属于当前计划、源状态为待办且依赖已由当前证据判定就绪。阻塞、暂停、未知或未就绪任务不会被自动恢复或替换；验证选择取自计划，而非请求。
- 明确来源必须是工作区内的普通 UTF-8 文本文件，不接受路径逃逸或软链接。组装期间复核计划、请求及来源身份；发现变化停止对账，不覆盖外部修改。组装后到实际使用前的变化仍须运行调用方处理。
- 请求读取上限为 131072 字节；每个源码文件及去重后的累计源码读取上限均为 131072 字节。相同文件可同时保留在源码和未完成修改两节，其重复转发仍计入最终输入预算。
- 启动输入默认预算为 65536 字节，可设置为 256–131072 字节。计量包含完整 JSON、UTF-8 和转义开销，是字节近似，不是 Token 或费用计量；必要输入超限时阻塞，不裁掉约束、修改、反馈或未完成任务。
- `observed_host_bytes` 必须是非负整数或 null。整数计入启动预算但只表示调用方的部分观察；null 明确表示未知，零不等于未知。两者都不证明宿主附件、自动加载及旁路已全部覆盖。
- CLI 外层仍受 16384 字节输出上限限制，包括嵌套输入字符串的再次 JSON 转义。模块组装成功不保证 CLI 能完整输出；超限时不输出部分输入，不自动保存文件或启动 Agent。
- 累计工具输出原语默认单次上限为 16384 字节、单轮累计上限为 131072 字节，允许降低但不能提高硬上限。计入完整 JSON 结果而非仅日志正文；超限或结果非法后该实例保持阻塞，不能通过下一次小输出自动恢复。
- 累计输出原语完整保留业务裁决，序列化或日志保存成功不能把真实失败变为通过。目前仍需独立运行调用方接入；原语单测不能证明真实 Agent 全部工具经过预算入口。
- 目标、授权、约束与反馈仍是调用方声明；文件身份复核不证明这些声明有效，也不证明真实新会话或远程断开后推进。

相关反例见[预算测试](../../../../tests/test_context_guards.py)、[计划与源码组装测试](../../../../tests/test_context_inputs.py)及[实际入口测试](../../../../tests/test_exec_cli.py)。资产存在不代表当前运行通过。

## 套件读取租约与部署互斥

协作式租约见[套件租约模块](../../../../scripts/bmad_suite_lease.py)，套件内相关反例见[租约测试](../../../../tests/test_suite_lease.py)。公共部署互斥回归属于来源仓库的工程验证，不作为分发后本地导航或运行依赖；其定位由获准计划的验证矩阵提供。测试资产存在不表示当前运行已经通过；此模块没有对应的 CLI 子命令。

- 租约仅持有已部署根目录内现有固定部署锁的共享锁，不创建目录、锁、来源记录或任务状态。缺失锁、权限拒绝、链接或特殊文件均拒绝进入，不隐式准备环境。
- 遵循同一锁协议的受管部署写入在租约期间无法获得排他锁；多个工作区可以共享读取同一套件，但这不提供任务工作区的单写入者保护。
- 进入与正常退出边界复核锁文件身份；发现外部替换时停止对账，不恢复旧锁、不覆盖外部修改。调用方原始失败或取消继续传播，不由退出检查改写为成功。
- 调用方必须先核验套件来源，并在所有 Agent 和验证子进程确认结束后才释放租约。租约自身不核验来源、不启动或取消进程，异常离开即释放本描述符，不能据此声称在途进程已经结束。
- 当前尚未接入任务期循环；原语与部署子进程互斥不证明真实活动任务持有租约，也不证明宿主加载、权限隔离或远程断开后推进。
- 对已有部署，公共部署入口的真实仓库更新、分支切换及标签缓存准备已接入固定部署锁的排他守卫；持有共享租约时，在这些版本动作之前拒绝执行。排他描述符跨新版入口移交保留，最终受管部署仅借用，不释放外层锁。此能力属于来源仓库的公共部署设施，不是套件内新增的验证子命令或分发后运行依赖。
- 继承描述符必须通过 Linux 内核锁记录核验，不能仅凭环境标记或描述符编号认定持锁。已有部署缺失锁时失败关闭，不补造锁；尚无部署状态的新安装沿用首次部署预检，不为版本动作创建状态目录。只读版本预览不获取排他锁。
- 上述防护仅覆盖遵循协议、针对同一部署根调用公共入口的操作；直接修改来源仓库、通过其他部署根操作共享来源或不遵守锁协议的写入不在保证范围。来源绑定原语见下节，尚未接入活动任务或任务期循环，不能据此宣称全部来源已冻结、真实任务受保护或取消后在途进程已结束。
- 同账号删除或替换锁、不遵守协议的写入、持锁进程崩溃以及仍存活的子进程均不在保证范围。只读预检和状态查询不获取写入权限，也不释放其他进程的租约。

## 已部署 V5 来源绑定

来源核验与租约组合见[来源绑定模块](../../../../scripts/bmad_suite_source.py)，本地反例见[来源绑定测试](../../../../tests/test_suite_source.py)。真实公共部署产物的兼容性测试位于来源仓库，由获准计划的验证矩阵定位，不构成分发后运行依赖。此模块没有对应的 CLI 子命令，不启动 Agent、不保存任务进度。

- [绑定入口](../../../../scripts/bmad_suite_source.py)先取得明确部署根内现有锁的共享租约，再核验 V5 身份、已部署来源记录、受管文件摘要与权限，以及源码到插件和规则副本的分发映射。来源未知、版本不符或资产缺失时阻塞，不回退 V4、不补造来源记录。
- 仅读取部署根内的物理资产，不访问记录中的来源仓库。提交与差异字段描述部署时记录，不证明当前仓库 HEAD、远程版本或源仓库已经冻结；一致性核验不提供同账号防篡改保证。
- 插件物理文件集合必须与来源记录及生成清单精确匹配。额外文件、软链接、特殊文件、多硬链接、非法路径或超出读取预算均阻塞；不删除额外资产、不恢复旧文件、不覆盖用户修改。
- 采集期间、显式边界复核及正常退出时检查观察到的资产身份与集合。已绑定来源即使连同清单被一致改写，也须停止对账；调用方原始失败或取消继续传播，不由退出复核掩盖。
- 当前仅核验受管模式记录结构及其与来源清单的一致性，不读取宿主模式目标、不核验其语义，也不核验部署事务日志是否全部完成。来源绑定不能替代完整部署状态诊断、运行时加载、权限或恢复门禁。
- 来源绑定与共享租约仍是供运行调用方使用的原语，尚未接入活动任务或任务期循环。调用方必须确认所有 Agent 与验证子进程结束后才能离开绑定；异常退出释放描述符不等于在途进程已清理。

## 计划内唯一任务清单

解析与只读投影见[状态模块](../../../../scripts/bmad_state.py)。采用本契约须在接管或契约变化边界明确决定；完整 frontmatter、关联 ADR、授权及阶段仍须按核心规则核验，状态模块不替代这些校验。

计划中使用唯一的 `bmad-tasks` JSON 围栏。以下仅为结构示例，所示测试文件及环境不是已存在或已通过的声明，实例化时必须替换为当前获准目标。

```bmad-tasks
{
  "schema_version": 1,
  "plan_id": "EXAMPLE-PLAN-01",
  "tasks": [
    {
      "task_id": "T1",
      "title": "运行获准的相关单测",
      "depends_on": [],
      "status": "PENDING",
      "verification": {
        "operation": "unit-test",
        "environment_file": ".bmad-control/environment.json",
        "directory": "tests",
        "pattern": "test_sample.py",
        "minimum_tests": 1,
        "required_tests": ["test_sample.Sample.test_sample"],
        "inputs": ["implementation.py"]
      },
      "verdict_file": null
    }
  ]
}
```

- 顶层仅包含 `schema_version`、`plan_id` 和 `tasks`；版本为整数 1，计划标识须与 frontmatter 一致，任务数量为 1–256。
- 每项仅包含示例中的六个任务字段；标识唯一，依赖必须存在且无自依赖或循环，标题为预算内单行文本。
- 源状态仅接受 `PENDING`、`BLOCKED`、`SUSPENDED`、`COMPLETED`。`READY` 是投影视图中的依赖就绪结果，不是可写入的源状态。
- 验证对象必须包含示例中的全部七个字段，当前只接受 `unit-test`。路径为工作区内明确相对路径，列表不得重复，测试下限必须是大于零的整数。
- `COMPLETED` 必须引用已有验收回执；模型写入完成状态不能制造通过事实。投影会复核证据及当前任务的测试选择、实现输入和环境定位是否精确匹配。
- 已完成项的证据失效或依赖未完成时，有效视图将其阻塞，不修改原计划、不推进下游；暂停项不被隐式恢复。
- 待办项即使已有有效回执，也不会因只读查询自动转为完成。当前接口没有完成写回操作，不得将候选投影描述为完整任务控制器。
- 回执没有计划／任务专属签名，匹配验证选择不等于证明独立任务身份；同账号可修改全部证据时不宣称防篡改。

## 输出与接管边界

- 状态视图必须完整保留全部任务，至多 80 行且受字节预算限制；无法完整表示时阻塞，不静默截掉未完成事项。
- JSON 转义、回执定位及结果元数据也计入 CLI 输出预算。完整结果超限时返回阻塞，不将截断视图包装为成功。
- `render-state` 的退出零仅表示该次投影未返回 `BLOCKED`；可能仍为 `READY` 或 `SUSPENDED`，不表示任务或全计划完成。
- 即使所选清单全部完成，也只反映该清单当前覆盖的验证契约，不证明全计划其他门禁、宿主权限、远程断开行为或 ADR 转正条件。
- 未采用此契约的活动计划继续以平台任务记录作为唯一临时进度入口；不能同时在原清单和平台记录镜像进度。
- 本页不授权迁移当前活动计划。迁移必须核对所有未完成事项、明确进度所有权切换并重验受影响证据，不继承历史绿灯。
