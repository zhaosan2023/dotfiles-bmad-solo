# 本地任务期循环与活动计划适配

本页定义接口和证据边界，不保存任务进度或测试通过记录。当前支持本地单测循环及隔离无头驱动抽象；真实 Roo 的来源、版本、无头参数、独立认证、权限与远程断开行为尚未核验，真实运行时失败关闭。

## 入口

入口见[循环 CLI](../../../../scripts/bmad-loop.py)，实现见[循环模块](../../../../scripts/bmad_loop.py)、[计划适配层](../../../../scripts/bmad_plan_adapter.py)和[驱动协议](../../../../scripts/bmad_agent_backend.py)。

- 启动必须指定获准工作区、唯一结构化任务清单、输入请求、后端与预算。前台同步等待，不安装依赖，不创建永久调度器。
- 无计划参数的查询读取当前循环回执与协作租约；明确指定计划时只读查询就绪任务及完整短状态卡，不启动 Agent、不保存进度、不重跑业务测试。
- 停止为当前运行实例写入取消请求，同步等待最终清理回执和工作区写租约释放。不依据陈旧 PID 发信号；等待超时或清理未确认时退出非零并保留成果。

```text
start --workspace PATH --plan-file RELATIVE_PLAN --request-file RELATIVE_REQUEST
      --backend {local-verification,roo-cli,headless,pi-agent}
      --maximum-rounds INTEGER --timeout-seconds SECONDS --no-progress-rounds INTEGER
      [--backend-config RELATIVE_CONFIG] [--credential-file RELATIVE_CREDENTIAL]
      [--save-progress]
      [--batch-file RELATIVE_BATCH] [--maximum-calls INTEGER]
      [--maximum-model-requests INTEGER] [--maximum-data-bytes INTEGER]
      [--deployment-root PATH --run-copy-file RELATIVE_BINDING]
      [--retry-delay SECONDS] [--startup-bytes INTEGER] [--output-bytes INTEGER]
      [--runtime-directory RELATIVE_DIRECTORY]
status --workspace PATH [--plan-file RELATIVE_PLAN]
stop --workspace PATH [--wait-seconds SECONDS]
```

以上是参数规约，不是可直接执行的工作区命令。实际路径、授权与预算须由接管契约明确。

## 活动计划与唯一任务进度

- 计划须明确采用[类型化验证契约](verification.md)中的唯一任务清单。适配层不把散文、旧复选框或计划中的命令转换成执行任务，不静默迁移或恢复暂停项。完整元数据、关联 ADR 与授权在接管、契约变化和阶段边界核验。
- 未指定批次时，一次启动只驱动请求明确指定的一个依赖就绪任务。指定批次并明确授权进度写回时，程序仅从显式获准集合选择依赖已由当前有效证据满足的任务；当前任务独立验证通过并保存后，在同一批次预算内自动选择下一获准任务，不执行集合之外的就绪项。
- 批次绑定计划标识及各任务独立请求，严格字段与读取边界见 [`load_batch()`](../../../../scripts/bmad_plan_adapter.py:31)。每轮重新组装当前任务、约束、定向源码和未完成成果；普通失败的退出结果、真实测试计数及有界日志反馈只传递给当前任务的新会话，不跨任务串线。完整验证未执行、必需项缺失或跳过不能作为普通失败修复重试。
- 默认不写回计划；明确启用进度保存后，程序核验真实 PASS 回执、当前验证选择、实现覆盖、环境和源计划版本，仅更新对应结构化任务。稳定目标、授权、其他任务、原 Epic 和 AC 保留。
- 状态卡只是任务清单的只读投影，至多 80 行并受字节预算约束；不能完整表示时阻塞，不静默丢弃未完成事项。全部结构化子任务通过也不证明范围外 Epic 或全计划完成。
- 计划写回复用工作区协作租约、保存前版本检查、原子替换及保存后复核；不宣称文件系统 CAS 或同账号防篡改。保存和查询不触发业务重测；相关实现、测试、契约或环境变化后，受影响旧证据须重新验证。

## 无头驱动契约

当前接受工作区内明确的 Python 适配驱动，文件传递输入，标准输入封闭。驱动契约为严格 JSON 对象，字段见[协议字段定义](../../../../scripts/bmad_agent_backend.py:23)。

- 明确声明后端、协议版本、运行时种类、来源、版本、驱动文件、授权说明、新会话、无头模式、凭据环境变量名称与驱动会话进程时限；字段缺失、重复或不匹配即阻断，不回退其他引擎。兼容旧字段 [`api_timeout_seconds`](../../../../scripts/bmad_agent_backend.py:25)，但它只限制整个驱动进程，不证明运行时内部的单次模型请求已限时。真实 Roo 后端不得声明为隔离夹具绕过门禁。
- 隔离夹具与明确获准的固定 Pi 后端分别处理。Pi 必须绑定[固定来源、版本及参数契约](../../../../scripts/bmad_agent_backend.py:82)，并接入[任务期流式转发](../../../../scripts/bmad_pi_transport.py:31)与[共享网络预算](../../../../scripts/bmad_pi_budget.py:21)；没有实际完整流式请求证据不能通过驱动调用。真实 Roo 仍因必需运行时实证未覆盖而阻断；配置声明不能代替真实验证，不自动安装或继承 IDE 登录态。
- 凭据仅探测指定环境变量是否非空，不把值写入命令参数、启动输入或控制器摘要。驱动进程继承宿主环境，完整日志可能包含驱动主动输出的敏感内容；本抽象不提供通用日志脱敏或账号隔离。
- 每轮新建驱动进程和随机会话标识；回执须精确匹配当前会话、计划与任务。新进程不证明实际 Roo 内部已经清空上下文。
- 驱动只收到请求文件参数；其中包含完整预算内启动材料和上一轮真实验证反馈。结构化结果须唯一、完整、有界，结果协议见[结果字段定义](../../../../scripts/bmad_agent_backend.py:28)。
- Agent 退出零和 OK 回执仅表示驱动调用成功。只有之后独立执行的相关单测与证据核验通过，才能保存任务完成；完成口令、文件变化、日志保存均不能替代业务验证。
- 认证失败、权限拒绝、非零退出、API／网络错误、结果缺失或不匹配、超时与清理不明明确阻断，保留现场，不循环询问凭据或重试认证。网络错误单独分类，不冒充代码失败。

## 项目私有凭据加载

[启动入口](../../../../scripts/bmad-loop.py:20)支持显式指定工作区私有凭据文件；[加载器](../../../../scripts/bmad_private_config.py:1)不执行 Shell，不读取系统全局配置或 IDE 认证文件。

- 凭据路径必须为工作区私有目录的直接子文件，限定见[加载器路径约束](../../../../scripts/bmad_private_config.py:16)。目录须为当前账号所有的 0700 普通目录，文件须为当前账号所有的单硬链接 0600 普通文件；拒绝符号链接、越界路径、非普通文件和读取期间变化。
- 文件最多 8192 字节，只允许一次 [BMAD_PI_API_KEY](../../../../scripts/bmad_private_config.py:17) 字面量赋值，可包含空行和整行注释。不执行命令，不支持变量展开、命令替换、多行值、其他变量或重复赋值；格式错误不回显正文。
- 仅显式启动无头任务时使用 [--credential-file](../../../../scripts/bmad-loop.py:22)。未指定时不探测私有文件，保留原环境变量接口；查询、停止及帮助不加载凭据，本地验证后端拒绝凭据文件参数。
- 指定私有文件时，在任务调用作用域内临时设置指定变量，正常或异常退出均恢复原环境。凭据不作为模型输入或命令参数；该进程内接口面向串行任务，不保证线程隔离或操作系统权限隔离。
- 非秘密网关后端配置与凭据分离。工作区版本控制忽略规则应排除私有目录；忽略规则不会移除已跟踪文件，也不保护项目外备份。不要把真实凭据放入分发套件、计划、ADR、回执或版本控制。分发文档不导航到工作区私有文件或套件外安装资产。
- 安装与部署入口不因该加载功能读取凭据或启动任务；凭据加载仅由[显式任务启动入口](../../../../scripts/bmad-loop.py:66)调用。加载成功只表示运行进程可取得指定变量，不证明网关认证、模型连通、真实工具权限或客户端断开后的自主执行；其他真实运行门禁仍须满足。

## 预算与停止

- 最大轮次通常为 1–1000；任务期总时限为 0.05–600 秒；退避为 0–5 秒。显式调用预算限制外层驱动启动次数，不等于模型请求数或费用。[Pi 启动契约](../../../../scripts/bmad_loop.py:68)必须明确最多 30 次真实网关请求、最多 15,000,000 字节请求与响应正文，以及 6 轮无进展熔断；失败请求不返还预算，跨会话不得重置。计量不覆盖网关内部重试、传输层开销、Token、费用或宿主工具旁路。
- 普通驱动会话仍为 0.05–30 秒；明确 Pi 会话允许至多 360 秒，且受任务截止时间进一步缩短。[监督器的 Pi 例外](../../../../scripts/bmad_supervisor.py:43)不扩大探测、验证及构建的 15/30/600 秒工具上限。
- 单次模型请求的运行时接口尚未核验，回执明确记录该限时覆盖为 UNKNOWN，不把驱动进程超时称为内部 API 请求超时。预算维度及实际截止时间见 [`timeout_dimensions()`](../../../../scripts/bmad_agent_backend.py:65)；涉及既有会话或工具上限扩大须另获明确确认。
- 启动输入、驱动 JSON 外层及最近反馈共同受启动字节预算限制；驱动结果和独立验证反馈共同计入本轮累计转发预算。采用 UTF-8 字节近似，不等于 Token、费用或宿主全部工具计量。
- 环境探测、证据采集和清理另有有界开销；任务截止时间不保证整个调用的精确墙钟上限。
- 普通验证失败不推进依赖，可在预算内继续当前任务。相关文件变化只影响无进展判定，不证明完成；持续无进展、轮次耗尽、缺依赖、预算不足或必需证据缺失均阻断。
- 明确停止或取消且清理已确认时保存暂停状态，启动入口退出非零。停止入口退出零仅表示停止已确认，不表示任务完成。
- CLI 完整结果超过输出预算时退出非零，不输出部分状态卡；可用时保留最终回执定位。完整回执的读取预算独立于 CLI 输出预算。

## 租约、日志与断网证据

- 固定工作区写租约不能通过更换日志目录绕过，仅约束遵循循环入口的启动者，不阻止编辑器、同账号写入或其他工具旁路。
- 本地隔离入口成对指定合成部署根与运行副本绑定回执，入口必须实际来自该绑定副本；分发源码入口不能仅凭声明冒充隔离运行。边界实现见 [`bound_run()`](../../../../scripts/bmad_task_run.py:169)，运行副本实现见[候选副本模块](../../../../scripts/bmad_run_copy.py)。本阶段仅允许授权工作区内的合成部署根，不激活真实宿主。
- 来源绑定与共享读取租约覆盖全部受管调用及清理确认；持久清理记录在租约释放后继续阻断清理未知的重启与公共部署操作。接管和阶段边界核验绑定，发现变化停止对账，保留用户修改，不恢复旧资产或旧进程。协作锁与同账号副本不等于系统权限隔离或跨部署根保护。
- 运行期间修改候选源码不得热替换当前绑定程序。升级必须先停止、确认全部受管进程清理、验证候选版本，再经获准边界启用；准备副本不是实际启用或真实 Agent 启动授权。
- 监督器清理新建同组子进程；清理不明禁止验证和后续启动。独立 Linux subreaper 夹具不代表生产监督器已实现收养；脱离会话、容器、任意后代和崩溃恢复不在覆盖范围。
- 日志及最终回执保存于授权工作区证据目录，当前查询视图原子替换。回执保留真实命令、工作目录、退出结果和目标；不保证同账号防篡改。
- 本地断网准备仅在隔离驱动中模拟连接失败，不修改宿主网络、防火墙或 SSH。当前本地步骤完成及回执落盘不证明关闭 IDE 后真实 Agent 能继续调用模型或开始下一任务，不通过全计划的远程断开门禁。
- 后续仍需真实 Roo 独立接口、新会话、规则/模式加载、独立认证及取消实证，以及真实试跑授权、权限隔离、真实部署根接入、远程两轮和费用测量。试跑前一次性确认工作区、写入范围、认证方式、时间、轮次、模型调用/费用预算和停止方式；当前交付不提交、不推送、不部署、不转正 ADR、不归档。
