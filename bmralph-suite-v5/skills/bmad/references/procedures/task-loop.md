# 本地任务期循环接口与边界

本页说明接口，不保存任务进度或测试通过记录。本地循环不是 Roo 独立 Agent 适配器，不证明新会话、认证权限或关闭客户端后自主编码。

## 已提供的入口

入口见[循环 CLI](../../../../scripts/bmad-loop.py)，实现见[循环模块](../../../../scripts/bmad_loop.py)。

- 启动：必须提供授权工作区、明确采用类型化任务清单的计划、输入请求、显式本地验证后端、最大轮次、任务时限和无进展阈值。启动在前台等待，不创建后台服务，不安装依赖。
- 查询：只读取当前程序回执和工作区协作租约，不执行业务验证，不保存任务进度。没有回执时返回 IDLE；启动者已退出但缺最终回执时返回 BLOCKED，不能声称已清理。
- 停止：为当前运行实例写入取消请求，同步等待最终清理回执与工作区写租约释放；不依据陈旧 PID 发信号。等待超时或清理未确认时退出非零，保留成果。

确切参数如下；实际运行时必须使用当前获准工作区、计划、输入请求与预算，不把示例路径视为现有资产。

```text
start --workspace PATH --plan-file RELATIVE_PLAN --request-file RELATIVE_REQUEST
      --backend local-verification --maximum-rounds INTEGER
      --timeout-seconds SECONDS --no-progress-rounds INTEGER
      [--retry-delay SECONDS] [--startup-bytes INTEGER] [--output-bytes INTEGER]
      [--runtime-directory RELATIVE_DIRECTORY]
status --workspace PATH
stop --workspace PATH [--wait-seconds SECONDS]
```

## 契约与实际覆盖

- 计划和输入请求采用[类型化验证契约](verification.md)中已定义的字段；环境须先显式登记。当前活动计划未迁移，循环不能直接执行缺少类型化任务清单的旧计划，也不自动迁移或恢复暂停项。
- 每次启动只验证请求指定的一个就绪任务，复用验证执行器的单测模块、完整日志、进程回执、验收回执和证据查询。每轮重新组装受预算约束的输入，不启动编码 Agent，不自主修复或选择下游任务。
- 请求目标、授权和反馈仍为调用方声明，不由循环证明有效。启动输入与转发的完整有界验证反馈按 UTF-8 字节计量，包含 JSON 转义和失败定位；不是 Token、调用费用或宿主全部工具计量。
- 最大轮次和无进展阈值均为 1–1000；任务时限为 0.05–600 秒；固定重试等待为 0–5 秒。任务截止时间只能缩短监督器的 30 秒单测上限，不提高分级超时。环境探测、证据采集及清理有额外开销，因此任务时限不是整个操作的精确墙钟上限。
- 无进展比较显式测试目录和实现输入的内容、权限与文件集合；文件变化不证明完成。持续无进展、轮次耗尽、超时、缺依赖、预算不足和必要证据缺失均返回 BLOCKED、退出非零并保留修改。
- 明确停止或信号中断在清理已确认后记录 SUSPENDED，启动入口退出非零。停止入口退出零仅表示停止已确认，不表示任务成功。
- COMPLETED 只表示请求指定任务的本地验证通过，不写计划完成状态，不证明 Epic 或全计划完成。平台任务记录继续作为当前活动计划唯一临时进度入口。

## 租约、清理与证据

- 工作区写租约使用固定控制路径，不能通过更换日志目录绕过；仅约束遵循循环入口的启动者，不阻止普通编辑器、同账号直接写入或其他工具旁路。
- 当前循环尚未接入已部署来源绑定和共享套件读取租约，不得在真实运行中据此宣称更新、回切或跨部署根来源已冻结。接管及轮次边界仅复核绑定计划、输入请求和已观察程序文件；不要求模型逐修改计算或同步指纹。
- 监督器清理其新建进程组，清理未确认时阻断后续启动。真实子孙进程测试的独立 Linux subreaper 夹具仅提供收养与回收条件，不是生产监督器能力；脱离会话、容器、任意后代与崩溃恢复不在覆盖范围。
- 运行日志和最终回执保存于工作区证据目录，当前查询视图原子替换；二者都不保证同账号防篡改。保存与查询不触发递归业务复验。
- 真实 Roo 新会话、认证权限、客户端断开后推进、费用预算、活动计划进度写回及部署来源绑定仍需单独实现和验证；不静默改用其他引擎，不转正 ADR、不归档或提交推送。

相关反例见[循环保护测试](../../../../tests/test_loop_guards.py)；文件存在不代表当前执行通过。
