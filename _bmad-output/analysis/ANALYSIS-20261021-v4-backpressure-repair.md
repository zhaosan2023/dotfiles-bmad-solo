- 日期：2026-10-21。
- 关联决策：[V4 人值守返修 ADR](../adrs/ADR-20261021-v4-attended-repair-and-repository-cleanup.md)，保持 PROPOSED。
- 关联契约：[V4 分阶段计划](../pending_implementation_plan.md)，计划标识 BMAD-V4-ATTENDED-CLEANUP-20261021-01；本次工程范围为阶段 0/1。

- 证据范围：客户端返回的仓库文件、差异及修改回执。静态文本修订不证明宿主加载、权限执行或效率提升；本报告不替代验证回执或唯一任务进度入口。

## 1. 审校结论

原交付物存在实际权限与入口文字冲突、验证示例不兼容、无依据效果断言及不充分的风险对冲，不能按“完整落地”接受。返修保留三遍阅读、证据分层与最小充分收敛，删除文字赋权、机械指标和未经测量的承诺；必要实验交给获准工程入口。

报告错放不是唯一问题：直接移动原文到 ADR 或分析目录仍会保留错误结论。修正后的分析放在本目录，决策由关联 ADR 承载，实施与验收由关联计划承载；旧位置保留明确退役的原稿及有效产物导航，仅供审校追溯，不继续充当规范。

## 2. 原报告的主要缺陷及修正

| 原报告内容 | 证据问题 | 修正后的结论 |
|---|---|---|
| 禁止分析终端必然造成死锁 | 把角色权限限制等同于没有任何取证渠道，未排除原生读取、搜索、官方文档及工程实验交接 | 权限冲突需要修复，但不能据此证明分析必须获得终端权限 |
| V5 显著更智能，释放 80% 注意力 | 没有同模型、同任务、同工具、同加载范围的对照记录；文本长度也没有可复核测量过程 | 用户体验是问题线索；因果解释与提升幅度均未证实 |
| 探针位于草稿目录即受控 | 脚本位置不限制执行时访问生产文件、网络或其他路径；未定位执行级隔离实现 | 草稿路径不是沙箱，不给分析入口新增探针执行权 |
| 差异检查可以阻止生产污染 | 事后差异检查不是预防式权限隔离，也不能证明覆盖未跟踪文件、项目外写入等副作用 | 差异审查只能提供其覆盖范围内的辅助证据，不能充当执行级防火墙 |

| 属性测试能低成本替代大量边界回归 | 未给出适用不变量、生成器、判定器及故障模型；把参数化与随机生成、收缩混用 | 参数化用例不自动具备随机生成或收缩能力；属性测试与缺陷回归及必要集成测试互补 |
| 只测被修改函数或模块的直接足迹 | 忽略调用方、共享接口、所有权和副作用传播 | 验证覆盖改动影响范围内的必要边界，不仅限被编辑函数，也不盲跑全库 |
| ADR 必须少于 50 行 | 没有证明固定长度可以保障决策质量 | 按决策需要保留理由、替代项、不变量及依据，不规定统一行数 |
| 每阶段一次确认、探针免审批 | 入口文本不能取消客户端审批或改变真实权限 | 操作按实际工具权限与当前用户授权进行，不承诺审批次数 |
| 两份文本已改即彻底解决死锁 | 缺少相关回归、受管分发及宿主有效加载证据 | 区分文字修改、静态验证、隔离分发与实际加载，不由前者外推后者 |

## 3. 两入口的真实契约

### 分析权限

[Roo 模式配置](../../bmad-suite-v4/roo/settings/custom_modes.yaml)的分析模式只有读取、受限编辑和浏览，没有终端权限组。因此，[原生分析技能](../../bmad-suite-v4/skills/ana-solo/SKILL.md)与[Roo 分析规则](../../bmad-suite-v4/roo/rules-ana-architect/01-ana-solo-core.md)不能宣称自主执行只读命令或探针。

- 分析使用实际可用的原生读取、搜索及浏览工具；只读任务仅会话交付，不写文件或运行验证。
- 获准结晶只写允许的分析报告、ADR 或计划；不强制每次同时生成多份文档。
- 必要实验交接明确问题、范围、环境前提和验收，另由获准工程入口执行；没有真实回执时保留未知。
- 模式展示、磁盘配置和静态路径正则不证明宿主实际加载或拒绝行为。

### 计划与验证

[现有计划模板](../../bmad-suite-v4/skills/bmad/references/templates/implementation-plan.template.md:20)与[校验器](../../scripts/validate-roo-contracts.py:175)支持的验证类型为 unit_test、config_syntax、diff_cleanliness。原示例的 footprint_property 不在支持集合，且示例命令没有契约要求的限时与封闭输入。

返修改为引用套件内真实模板，避免复制漂移的示例协议。未知会话标识保持空值；尚未创建的验证资产不能标记可用，可用也不代表已经通过。

工程验证依据实际授权和影响范围选择。普通失败允许预算内修复，但失败不推进依赖；超时、取消、缺依赖、零命中、必需项跳过或缺证据不通过。空输出是否满足验收依据具体操作判断，不能一律失败或一律成功。

## 4. 决策矩阵的审校

原矩阵没有定位评分证据、明确评分标尺或权重来源，且将“分析必须执行探针”设为硬门禁，预先排除了不扩大权限的替代方案。它不能证明推荐方案唯一胜出。[原硬门禁与评分表](../../docs/Ralph-Wiggum-Loop/dr_dm_v4_backpressure_optimization.md:121)

评分还存在算术错误：按原权重和分项，方案 B 的总分应为 71.0，而不是表中的 55.0。即使修正算术，评分依据与候选定义问题仍然存在，不能靠重新排序挽救裁决。[原分项与公式](../../docs/Ralph-Wiggum-Loop/dr_dm_v4_backpressure_optimization.md:133)

本次采用定性比较，不另造分数：

| 候选 | 优点 | 必要约束与代价 | 裁决 |
|---|---|---|---|
| 保持原交付物不变 | 不增加返修工作 | 保留实际权限冲突、无效示例及不实落地声明 | 不接受 |
| 给分析入口新增终端或探针权限 | 可能缩短部分实验交接 | 需要新的授权、执行级隔离与宿主权限验证，超出当前“不扩大分析权限”的范围 | 本任务不采用，不宣称其技术上永远不可行 |
| 对齐两入口，必要实测交给工程 | 不扩权，可复用已有工程验证路径 | 必须同步下层规则、核对实际回执，并接受必要的实验交接 | 当前获准返修路径；验证完成前不作为已验收结果 |
| 删除测试与决策门禁 | 减少部分流程步骤 | 不满足当前保留必需验收与失败关闭的目标 | 不采用 |

## 5. 反向审查与验收边界

- 下层规则重新引入越权：不能只修顶层两份文本，须核对共享核心、分析流程、工程交接与模式说明；相关断言覆盖这些入口。
- 只读任务被自动结晶：可行裁决不能自动进入写入、编码、转正或归档；必要实验也不能自动启动。
- 相关验证过度缩窄：保留调用方、共享接口及真实副作用边界，不能通过删去已发现缺陷的回归制造绿灯。
- 有条件对账被当成完成：缺少必需义务只能交付条件与未完成项，不能豁免阶段门禁。
- 进度复制到分析或 ADR：本报告保存审校依据，ADR 保存决策，计划保存契约；当前执行进度与真实回执仍只使用已选定的平台任务记录，未证明控制器覆盖时不宣称程序防篡改保证。
- 分发成功被当成有效加载：本地静态契约、项目内隔离分发及真实宿主加载是不同证据层，后续阶段不能跳过对应验收。

本报告不登记测试通过；旧位置已明确标注退役并保留原正文与导航，但这不证明运行绑定或在途进程已经结束。阶段验收、相关回归的真实结果及未完成事项仅在唯一任务入口中记录；宿主切换须另获明确目标与权限并核验在途进程，按[关联计划](../pending_implementation_plan.md)推进，不提前开展旧版本清理、不恢复 V5、不自动转正或归档。
